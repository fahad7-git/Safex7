# Safex7 - Phishing URL Scanner

Safex7 is a web application that helps detect phishing URLs using machine learning.

## Features

- URL phishing detection using ML model
- Rule-based analysis
- Real-time scanning
- User-friendly React frontend
- Python Flask backend

## Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Python, Flask
- **ML**: scikit-learn, joblib

## Getting Started

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```
